# Requirements and Conceptual Model.
Names: Djeneba, Gbolahan, Richard


# End User
School administrators who need to manage student and course information.

# Requirements
- Add and update student information.
- Track which courses students are taking.
- Record student grades.
- View teacher and course information.

# Categories of Data
# Students
- Student ID
- First Name
- Last Name
- Email
- Age
# Courses
- Course ID
- Course Name
- Course Description
# Grades
- Student ID
- Course ID
- Grade
# Teachers
- Teacher ID
- First Name
- Last Name
- Email
- Course
